Human-gated merge pack (DG-merge-v0)

Export a PR-ready preview after DG-v1 signed apply. Never auto-writes published case JSON. Signed proposals may also live in Worker DG-store-v0.

Steps

  1. Propose + dual-sign (DG-v1 fixture keys) on the steward shell.
  2. Persist to Worker store (DG-store-v0) and/or keep session cache.
  3. Apply — marks proposal applied; published case JSON unchanged.
  4. Download the merge pack (human-gated preview + case_after_merge).
  5. Human reviews sources + charter, then hand-edits site/data/docket-case-{id}.json.
