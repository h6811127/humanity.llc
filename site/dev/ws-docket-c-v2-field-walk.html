Mint steps (local)

  1. Starter-four cases are bound to /docket/{id}/ (interim casefile URL) under the nonviolence charter.
  2. Optional upgrade: unlock a steward parent card → create child_object → issue-qr.
  3. Then set scan_path to /c/{profile_id}?q={qr_id}; keep object_id = obj_docket_casefile_{id}.
  4. Preview the upgraded live_object on /docket/{id}/steward/ (#qr-upgrade) before editing published JSON.
  5. discovery_opt_in must stay false until C-v3 (docket stays an opt-in branch).

Surfaces

  • /docket/ — roster (interim case URL binds)
  • Steward shell example — #qr-upgrade
  • /created/ — create + issue QR with owner key
  • QR field kit — print → case → action
