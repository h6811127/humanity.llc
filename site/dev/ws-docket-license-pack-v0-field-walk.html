Photo license packs (license-pack-v0)

Formal attribution gate before any face goes live. Starter-four Most Wanted stay not_licensed. Rehearsal pack proves the licensed render path with non-person artwork.

Steps

  1. Fill a pack row: subject_id · photo_ref · license.type · attribution · source_url · obtained_at.
  2. Store the likeness under /assets/docket/ (site path only — no hotlinks).
  3. Set pack status to ready only when the asset file exists and fields validate.
  4. Apply ready pack → checklist license_status=licensed + matching photo_ref.
  5. Starter-four Most Wanted packs stay draft/awaiting_assets — never auto-apply without a real license.
  6. Caption remains “Public likeness · not a mugshot”. Fail open to monogram otherwise.

Surfaces

  • Packs registry
  • Rehearsal asset
  • Steward #photos (pack status)
  • Most Wanted (starter-four monograms)
