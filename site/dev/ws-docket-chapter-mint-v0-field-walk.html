Chapter child QR mint (QR-mint-v0)

Mint a real Worker status_plate + child QR for non-starter chapter pins. Never starter-four. Never city discovery. Keys stay in worker/.local/.

Steps

  1. Confirm starter-four stay discovery_opt_in: false (never mint Most Wanted into city discovery).
  2. Start local Worker: npm run worker:migrate:local && npm run worker:dev
  3. Run: API_ORIGIN=http://127.0.0.1:8787 npm run ws-docket:chapter-mint -- --write-pins
  4. Confirm /docket/chapters/ shows mint_status minted + real /c/{profile}?q={qr} path.
  5. Keys stay in worker/.local/docket-chapter-mint.json (gitignored) — never commit.
  6. Production: same script with API_ORIGIN=https://humanity.llc only when intentionally minting prod.
