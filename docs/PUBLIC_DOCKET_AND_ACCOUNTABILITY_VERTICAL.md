## One-sentence thesis

> The physical internet is the **center**; the Public Docket is a **load-bearing vertical** on those rails — a nonviolent, evidence-based accountability campaign machine that withdraws legitimacy from unjust power, coordinates civic action, and builds network goods in parallel — never a hit list, never celebration of harm.

**North-star line (official copy):**

> We don’t overthrow people. We withdraw legitimacy from unjust power and build what deserves it.

---

## Why this exists

This vertical is one branch of the physical internet: shared public casefiles for **public figures and institutions**, with sourced counts, allowed civic actions, local chapters, and annual rituals that celebrate **documented outcomes** — not elimination of persons.

It is intentionally **not** the front door of humanity.llc. Strangers’ first scan should still feel like: *the world has a live layer*. People who opt into accountability go deep.

**Revolutionary intent (definition used here):** durable shift in who holds power and how — habits, institutions, legitimacy — via diagnose → refuse → replace → ritualize. Not violent overthrow, not Hunger Games framing, not celebrating deaths or “taking people out.”

## Center vs branch (architecture decision)

| If accountability is the **center** | If it is a **branch** (chosen) |
|-------------------------------------|--------------------------------|
| Every QR smells like politics | Stickers stay open: lost keys, games, rooms, goods |
| Partners and cities hesitate | Docket is opt-in depth, not the homepage |
| Optimize for conflict | Optimize for **presence in the world** |
| One narrative owns the network | Many narratives share the same rails |

```text
Physical internet (center)
├─ Live objects / rooms / discovery / games
├─ Network goods / local coordination
└─ Public Docket / accountability (branch)
      inherits: QR, place, stewardship, ritual
      adds:     evidence, nonviolence rails, campaigns, outcome logging
```

**Why branch-with-teeth is coherent**

- **Depth, not width** — most scans never see the docket; chapters and campaigns go deep.
- **Same body, different organs** — physical internet = nervous system; docket = one organ.
- **Credibility transfer** — a network trusted for boring local utility can host hard civic work.
- **Exit safety** — a hot docket can be frozen without burning the substrate.

**Risks to design against**

| Risk | Failure mode | Mitigation |
|------|--------------|------------|
| **Orphan branch** | Side page with no stewards, rituals, or actions | First-class vertical: rooms, discovery opt-in, Accountability Day, metrics |
| **Brand bleed** | Every sticker reads as “the wanted app” | Charter + naming discipline; default stranger path unchanged ([`MOVEMENT_NARRATIVE.md`](MOVEMENT_NARRATIVE.md)) |

**When to make it more central:** only if the company purpose *is* withdrawing legitimacy from unjust power as the primary product promise — then rename and re-home; do not half-do both.

## Nonviolence charter (non-negotiable)

Ship on **every** case page and nomination surface:

1. **No violence, threats, stalking, or doxxing** — no private addresses, no “how to find/harm,” no celebration of injury or death.
2. **Allowed actions only** — petition, boycott, shareholder vote, FOIA / public records, peaceful protest information, contact elected representatives, donate to legal aid / journalism, share verified sources, local teach-ins.
3. **Evidence bar** — each count needs a source (court docs, official records, reputable reporting). Label **opinion** vs **allegation** vs **adjudicated fact**.
4. **Defamation hygiene** — prefer attributed claims (“X reported…”, “court filing claims…”) over absolute accusations; link primary sources; publish a corrections path.
5. **Public figures / public acts only** — no recruiting tips on confronting private persons; prefer migrating pressure to **institutions** (office, company, ministry) when a face leaves power.
6. **Moderation + appeals** — who nominates, who verifies, how a case closes or retracts; bans for violence-adjacent content.
7. **Success = outcomes, not vibes** — metrics like “divestment target met,” “FOIAs filed,” “bill passed,” “settlement published” — never “person is gone.”

**Red lines (ban forever examples — finalize in governance):** threats of violence; doxxing; calls to harass private individuals; content that treats death/elimination as a win.

## What makes it powerful

Power means **coordination that changes incentives**, not louder outrage.

| Lever | Why it’s strong |
|-------|-----------------|
| **Receipts beat vibes** | Claim → source → counter → status. Citeable by journalists and lawyers. |
| **Action is the product** | The list is an index; the product is “this week, do *this* with *these people*.” |
| **Local × global** | Global narrative + local chapters, sticker/QR drops, teach-ins on physical internet rails. |
| **Stewardship as legitimacy** | Visible maintainers, quorum/dual-gate edits, public changelog, correction path. |
| **Outcome theater (ethical)** | Accountability Day celebrates closed loops with receipts — spectacle without blood. |
| **Network goods, not ragebait** | Shared research kits, legal templates, open datasets, translation packs; each chapter upgrades the commons. |
| **Single metric per case** | Progress bars create momentum (e.g. “X% of target banks exited”). |
| **Institutional targets** | Boards, funds, advertisers, regulators — where decisions happen. |
| **Timed campaigns** | 30-day sprints with public scoreboards beat eternal doomscroll. |
| **Counter-docket** | Host the other side’s best argument — court of record, not mob. |
| **Exit criteria published first** | “Off the docket when ___” — fairness is a power move. |

**Attention ≠ power.** Naming high-profile cases gets attention. Power is: trusted evidence → repeated coordinated action → institutional pressure → visible outcomes → a culture that refuses violence so it can scale legally and socially.

**12-month “powerful” signals (aspirational)**

- A regulator, paper, or NGO cites a case page.
- A city hosts Accountability Day with packed teach-ins, not chaos.
- One measurable institutional shift partially attributable to coordinated action.
- New cases follow the same rigor — brand means “serious,” not “angry.”

## Case architecture

```text
Case (public figure and/or institution)
  ├─ Counts (sourced claims; labeled opinion / allegation / fact)
  ├─ Counter-docket (replies, rebuttals, target submissions — strength, not weakness)
  ├─ Action queue (ranked by leverage × legality × ease; geo-aware)
  ├─ Local chapters (events, stickers, meetups, teach-ins)
  ├─ Progress (metric + receipts)
  └─ Close / reopen (rules-based; publish criteria before launch)
```

Think **live object / QR casefile**, not a ranking of enemies:

- **Case** → steward room + optional discovery pin (opt-in).
- **Scan** → why this case · evidence · what you can do this week · what we never do.
- **NGI / network goods** → research kits, templates, shared datasets shipped *alongside* campaigns so the vertical is not only oppositional.

### Starter cases (templates — not hit posters)

Until fuller NGI tooling exists, ship **case templates** for:

| Case | Example nonviolent focus | Example success signals |
|------|--------------------------|-------------------------|
| Benjamin Netanyahu | Policy, court/ICC records, press freedom — all sourced | Legislative/diplomatic milestones, verified reporting |
| Vladimir Putin | Aggression, sanctions, war-crimes documentation from official/NGO sources | Treaty/sanctions/investigation milestones |
| Sam Altman | AI governance, labor, concentration of power | Policy commitments, audits, regulation wins |

Each page structure: **Why this case** → **Evidence** → **What you can do** → **What we never do**.

Cases should be able to **migrate to institutions** when a person leaves a role so the method outlives the face.

## Inspiring transformative change (nonviolent “revolution”)

Movements that change orders usually do four things at once:

| Function | Docket’s job |
|----------|--------------|
| **Diagnose** | Shared map of abuse of power (sourced, contested) |
| **Refuse** | Coordinated withdrawal of consent (boycott, labor, attention, capital) |
| **Replace** | Visible mutual aid / public goods / local assemblies (NGI) |
| **Ritualize** | Recurring public moments that renew identity (Accountability Day) |

Inspiration is not rage posts. Inspiration is:

- Proof someone like me acted and it mattered (local wins, receipts).
- A role I can step into tomorrow (researcher, steward, chapter host, translator).
- A future that feels buildable, not only a past that feels damned.
- Discipline — the movement that refuses violence/harassment is the one fence-sitters and institutions can join.

The product sells **membership in a method**, not fandom of enemies. The docket is the curriculum; chapters are the organizing layer; public goods are the flag.

## Blind spots (what we must not forget)

| Blind spot | Why it matters |
|------------|----------------|
| **Backlash machine** | SLAPP suits, platform bans, doxxing of stewards, false-flag violence blamed on the project, attention capture. Plan legal defense and a public “we don’t do X” record before launch. |
| **Capture by the vibe** | Loudest users turn it into a hate shrine. Ruthless moderation + exit criteria required. |
| **Substitution effect** | Share the docket → feel done. Every surface ends in a **next action** or **chapter**. |
| **Becoming the institution** | If we own “the truth,” we are a new opaque priesthood. Counter-dockets, changelogs, “how to falsify this claim.” |
| **Empty middle** | Elites and online radicals mobilize; ordinary locals don’t. Kitchen-table paths: 20-minute actions, multilingual kits, childcare at events, offline-first QR. |
| **Victory without successor order** | Toppling legitimacy of X without a replacement story (mutual aid, new governance, public goods) creates chaos authoritarians exploit. Build while pressuring. |
| **Moral injury / burnout** | Atrocity exposure wrecks organizers. Rotation, care roles, “closed for the week” norms. |
| **International unevenness** | A tactic that is legal speech in one country is dangerous in another. Geo-aware action kits; never one-size-fits-all. |
| **Joke / brand problem** | “Most wanted” is sticky and radioactive for NGOs/venues/funders. Public name + folk name + charter on both. |
| **After the villain** | Person leaves; system remains. Migrate cases to institutions. |

- What speech do we refuse even if it “helps engagement”?
- What’s our response when someone posts a threat “in our name”?

### Governance

- Who can open a case? Close one? Veto violence-adjacent framing?
- How do targets (or their counsel) submit corrections?
- What happens when founders disagree with the crowd?

### Power analysis

- For each starter case: which **institution** actually moves if we succeed?
- What’s the smallest win that would prove the method?
- Where are we weak (money, law, attention, local trust)?

### Inclusion

- Who is centered that isn’t already online and angry?
- How do affected communities show up as **subjects**, not props?
- What languages and offline channels are day-one?

### Failure modes

- What does “we accidentally became a cult” look like in metrics?
- What does “we got used by a state or party” look like?
- When do we shut a case down for our own integrity?

### NGI / build track

- What public good ships in parallel with the first campaign?
- How do QR / rooms / discovery make belonging physical without polluting the default stranger path?

### Narrative

- One-sentence invitation to a skeptical friend?
- One-sentence invitation to a journalist?
- Forbidden vocabulary on official surfaces? (see Language section — expand as glossary)

## Dual-gate steward edits (DG-v0)

**Decision (locked 2026-07-16):** Case mutations that change counts, notes, CTAs, or status require **two distinct** `stewards[].id` approvals before apply.

| Piece | Behavior |
|-------|----------|
| Stewards | ≥2 on every case (`hc-founders` + `hc-reviewer` interim) |
| Proposals | `edit_proposals[]` optional on case JSON; steward shell + **Worker DG-store-v0** |
| First gate | Proposer’s id is recorded in `approvals` on create |
| Second gate | Different steward id must approve → status `approved` |
| Apply | Marks `applied` + emits changelog line; **does not rewrite** public case field values (human JSON review) |
| Surface | `/docket/{id}/steward/` → `#dual-gate-edits` |
| Code | `docket-edit-proposal-core.mjs` · `docket-edit-proposal-sign-*.mjs` · `docket-edit-proposal-store-core.mjs` · steward shell |

| **DG-store-v0** | **Shipped** — D1 GET/PUT `/.well-known/hc/v1/docket/{id}/edit-proposals` · steward sync · `npm run ws-docket:dg-store-preflight` |

**Not yet:** production steward key custody · auto-write of published case JSON.

## Closed-case criteria + exit rules

**Decision (locked 2026-07-16):** Publish **how a case leaves the open roster** before expanding nominations. Closed cases **remain listed** (muted) — history over deletion.

### Global rules (all cases)

A case may move to `status: "closed"` only when **one** of the following `closed_kind` values applies and is published with `closed_reason`:

1. **`outcome_logged`** — citeable civic/institutional receipt (policy, court milestone, divestment, audit, election result). Celebrates the receipt — never harm to a person.
2. **`migrated_institution`** — person left the role; pressure moves to office/company/ministry/successor case.
3. **`retracted`** — primary count failed the evidence bar; correction published.
4. **`integrity_hold`** — stewards pause/close for capture, weaponization, or unacceptable project risk.
5. **`superseded`** — replaced by a better-scoped case; link successor in `closed_reason`.

Never a closed reason: death, disappearance, injury, “taken out,” or any harm to a person.

`status: "monitoring"` = still on the docket, campaign paused or waiting on a process (e.g. pending court step).

### Published criteria surface

Global criteria live in `DOCKET_CLOSED_CRITERIA` and render on `/docket/#closed-criteria`. Case pages link there from `#exit-criteria` (summary) and show `closed_kind` + `closed_reason` when closed.

### ToS — removal for violence-adjacent content

**Decision (locked 2026-07-16):** Official Public Docket surfaces and any user-submitted counter-docket / tip content are removed (and submitters banned from docket tools) for:

| Ban forever | Examples |
|-------------|----------|
| Violence / threats | Calls to harm, “take out,” celebrating injury or death |
| Stalking / doxxing | Private addresses, “how to find,” non-public contact maps |
| Harassment of private persons | Recruiting tips to confront non-public figures |
| LE impersonation | Fake warrants, agency seals, FBI/WANTED chrome in submissions |

Corrections and good-faith rebuttals are **encouraged** via `#corrections` / `#counter-docket` — never via threats.

Roster surfaces this under `#tos`. Full product ToS may absorb this language later; until then the docket charter is the binding surface rule.

### Corrections + counter-docket (slot)

| Surface | Behavior |
|---------|----------|
| `#corrections` | Mailto path with case subject; invite sourced corrections from anyone, including targets / counsel |
| `#counter-docket` | Always visible slot — `open_for_submissions` until a reply summary ships; strength, not weakness |
| Steward visibility | v1 = `#stewards` + `#changelog` on case pages; **WS-DOCKET-C v1** = declarative `live_object` + steward shell; Worker-signed casefile mint = later |

## Network Goods Institute stack — how it composes

**Source (2026-07 research):** [networkgoods.institute](https://networkgoods.institute/) · [Index Wallets preprint](https://preprint.indexwallets.org/) · [negationgame.com](https://negationgame.com) / [play.negationgame.com](https://play.negationgame.com) · GitHub [`network-goods-institute`](https://github.com/network-goods-institute/)  
**Composition grammar:** [`PUBLIC_REALITY_LAYER_VISION.md`](PUBLIC_REALITY_LAYER_VISION.md) (L1 Humanity · L2 Negation · L3 Index)

NGI designs coordination mechanisms across three problem classes. Only some map into the Public Docket; others are adjacent pattern sources.

### NGI product map

| Product | Problem class | What it is | Maturity (public) | Role in *this* system |
|---------|---------------|------------|-------------------|------------------------|
| **Index Wallets** | Externality pricing | Programmable wallets with **index payments**: once currencies enter a wallet they exit only as a **proportional mix** of everything held; recipients set **endorsements** (how much they value each currency), which creates conciliation premiums and “selfish” voluntary taxation for public-goods currencies | Preprint + demos + Rust backend / Delta experiments | **L3** — fund resolver ops, chapter kits, legal defense, Accessibility Day — **never buy case verdicts** |
| **Negation Game** | Epistemic incentives | Protocol for reasoned disagreement: Points / Negations / Rationales; Cred & Favor; Restake / Slash / Doubt (reward stating what would change your mind); Spaces; AI assistant. Separate **Multiplayer Boards** = collaborative argument maps *without* Cred economics | Live product (AGPL); WIP | **L2** — counter-docket & contested counts live *beside* signed case state |
| **Louie** | Epistemic / civic memory | Ingests municipal transcripts, agendas, minutes → plain-language search with links to exact moments + structured argument map (who said what / debated / decided / left open). Mississauga demo; municipal outreach toward Oct 2026 elections | Early civic deployment | **Local memory rail** — chapter + city accountability without needing a famous-person case |
| **Litmus** | Epistemic incentives | AI + expert network + structured forecast elicitation for **FDA drug-approval** predictions; research question: extract what humans know that AI doesn’t, reproducibly | Domain-specific CI experiment | **Pattern source** for calibrated forecasts on docket metrics — not a docket dependency |
| **Power regulation** | Capture | Called out as a NGI problem class; **no dedicated product yet** — “designing against capture is built into the work” | Gap | Our **nonviolence charter, exit criteria, counter-docket, steward quorum** are our capture-resistance until shared tooling exists |

NGI also references broader mechanism lineage (quadratic funding, connection-oriented cluster matching) and publishes formal models alongside code.

### Index Wallets — mechanism → docket use

**Mechanism (compressed):**

1. Wallet holds a **vector** of currencies (USD + “cause” / public-goods tokens, etc.).
2. Every payment is an **index payment**: proportions match the payer’s portfolio; currencies are **permanently mixed** (cannot peel off only the “nice” token).
3. Recipients set **endorsements** per currency → conciliation pricing → communities with shared values transact cheaply; extremism (near-zero endorsements) is economically costly.
4. Net effect NGI claims: **voluntary taxation in the payer’s interest**, public-goods funding, and wealth-regularizing dynamics (see preprint).

**Futuristic system uses (Humanity + Docket):**

| Use | How |
|-----|-----|
| Stewardship pools | `stewardship_pool_ref` on network / case charters → Index cause for resolver hosting, audits, bilingual kits, Accessibility Day |
| Chapter treasuries | Local chapters accept index payments that mix “Cedar Rapids commons” + “case research kit” currencies |
| Parallel public goods | Campaign success includes **funding a good**, not only pressuring a target |
| Merchant / venue path | Cafés or print shops accepting index payments become physical on-ramps (pairs with QR field ops) |

**Hard rules:** Index flows **fund maintenance and goods**. They must **not** gate who may edit evidence, close a case, or appear “more true.” Funding ≠ truth ([`PUBLIC_REALITY_LAYER_VISION.md`](PUBLIC_REALITY_LAYER_VISION.md)).

**Engineering posture today:** declarative link / cause ID only; no Index crypto in the humanity.llc core loop; no token governance of signing keys.

### Negation Game — mechanism → docket use

**Mechanism (compressed):**

- **Point** = claim; **Negation** = structured counter; **Rationale** = packaged argument graph.
- **Cred** = scarce endorsement power; **Favor** = community belief metric.
- **Restake** = “I will reconsider if this negation holds” (epistemic leverage / influence for stating falsifiers).
- **Slash** = acknowledge mind-change (costly honesty); **Doubt** = bet the restaker won’t slash.
- **Spaces** = topic/community contexts; **MP Boards** = real-time collaborative maps without Cred.

Philosophical aim (NGI essay): reward *“I am the kind of person who is good at changing their mind”* — soften dogmatic identity; elevate intellectual honesty over narrative dominance.

**Futuristic system uses:**

| Use | How |
|-----|-----|
| Counter-docket | Each Public Docket **count** links via `dispute_ref` to a Negation Space or MP Board |
| Steward discipline | Case stewards restake on “we will revise if X primary source lands” |
| Close/reopen legitimacy | Case status changes when contest graph reaches published criteria — still **steward-signed** on L1 |
| Chapter sense-making | MP Boards for local teach-ins (no crypto required for argument mapping) |
| Anti–hate-shrine | Economic + social cost for unfalsifiable rage claims; prefer calibrated disagreement |

**Hard rules:** Negation **annotates**; it never auto-writes L1 case state. Popular Favor ≠ adjudicated fact on the scan page.

### Louie — civic deliberative memory → docket use

Louie is the missing **local** half of accountability: not “famous defendant,” but “what did our city actually decide?”

| Use | How |
|-----|-----|
| Place-based cases | Docket chapters attach Louie-style memory for municipal votes, zoning, contracts |
| Accountability Day | Replay “what was promised / left open” from public record |
| Physical internet bridge | QR on a city hall board → L1 status plate + link into Louie search / argument map |
| Stranger path safety | Local Louie demos can ship **without** naming global elites — reduces brand bleed |

### Litmus — pattern transfer only

Litmus shows how NGI extracts calibrated human judgment beside AI research. For the Docket, borrow the **workflow shape** (structured elicitation, transparency, reproducibility) for forecasts like “will this FOIA succeed?” or “will divestment hit X%?” — optional later; not MVP.
